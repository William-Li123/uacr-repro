# UACR: Reproducible Anomaly Inspection

UACR combines a lightweight local anomaly detector with a three-field multimodal
verifier. This repository provides fixed experiment splits, training/evaluation
code, public resource download instructions, and a configurable reproduction
pipeline. Start with the [Chinese guide](开始复现.md) or the steps below.

## What is included

- Fixed train/validation/test manifests with relative image paths, reference images,
  prompts, label/type/explanation targets, and stable sample IDs.
- EfficientAD training and validation-only threshold calibration.
- Qwen LoRA training, unadapted-base evaluation, UACR routing and same-adapter SAEC.
- Accuracy, TypeHit-A/P, TypeF1, ExplainHit and large-model invocation rates.
- Optional fixed-local score/mask tables for a controlled routing comparison.

Images and large trained checkpoints are not distributed. Download public inputs
using [DATASETS.md](docs/DATASETS.md) and [MODELS.md](docs/MODELS.md).
There is no required private service, user account, server directory or previous
experiment cache. Trained adapters are generated by the training commands below;
no unpublished adapter download is assumed.

## 1. Install

Target environment: Linux, Python 3.10.12+ and an NVIDIA CUDA GPU. The development
GPU was an H100 80GB. The commands run sequentially on one selected GPU; training
on smaller GPUs may require lower batch size and a separate experiment config.

```bash
git clone https://github.com/William-Li123/uacr-repro.git
cd uacr-repro
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r requirements.lock.txt
python -c "import torch; print(torch.cuda.is_available())"
```

OpenCV on headless Linux may require `libgl1` and `libglib2.0-0` from the system
package manager. The lock file records the development package versions. A fresh
full-environment installation and all GPU training stages have not been certified
on every platform; see [VALIDATION.md](VALIDATION.md).

## 2. Download public resources

```bash
python download_resources.py --resource qwen25vl_7b
python download_resources.py --resource qwen35_9b
python download_resources.py --resource teacher
python download_resources.py --resource yolo
python download_resources.py --resource imagenette --extract
python download_resources.py --resource visa --extract
```

Get MVTec AD, MVTec LOCO, KSDD2 and GoodsAD from the official links and follow the
extraction layout in [DATASETS.md](docs/DATASETS.md). MVTec downloads require the
provider's form; this repository does not bypass it. Download scripts record
resource versions/hashes. Qwen revisions are pinned in `configs/models.json`.

All generated resources go to `work/`, ignored by Git. To place them elsewhere,
set `UACR_WORKDIR` to any writable directory **before all commands**, or leave the
default unchanged. Dataset roots are independently configurable with `--raw-root`.

## 3. Prepare data

```bash
python bootstrap.py --raw-root work/raw --check-only
python bootstrap.py --raw-root work/raw
python reproduce.py check
```

Preparation preserves every ID, split, target, prompt and reference choice. It
does not randomly re-split datasets. Runtime manifests use resolved local paths.
Only normal training queries feed EfficientAD; its monitoring directory contains
validation images, never held-out test images. On Windows, use `--copy` if links
are unavailable. GPU training is supported/documented for Linux, not macOS.

## 4. Run the complete pipeline

Inspect the command plan first; this does not launch training:

```bash
python pipeline.py --run experiment1 --dry-run
CUDA_VISIBLE_DEVICES=0 bash run_all.sh --run experiment1
```

The default `retrain-local` protocol trains EfficientAD, scores validation/test,
calibrates thresholds on validation, rebuilds SAEC masks, trains eight three-field
adapters (two backbones times four training datasets), infers both adapted and
unadapted models on validation/test, selects UACR q on validation, and reports test
metrics. KSDD2 uses the fixed MVTec AD adapter for both UACR and SAEC.

To limit an experiment to the four paper benchmarks, pass the same dataset list
to preparation and the pipeline:

```bash
python bootstrap.py --raw-root work/raw --datasets mvtec_ad_80p mvtec_loco_80p visa_80p ksdd2_mvtlike
python pipeline.py --run paper4 --datasets mvtec_ad_80p mvtec_loco_80p visa_80p ksdd2_mvtlike
```

This trains six adapters. Use a fresh `UACR_WORKDIR` when changing a prepared
dataset configuration. Include MVTec AD whenever KSDD2 is evaluated.

## 5. Inspect results

```text
work/runs/experiment1/
  efficientad/           trained local detector weights
  adapters/              trained three-field LoRA weights
  predictions/           adapted-model val/test predictions
  base_predictions/      unadapted-model val/test predictions
  uacr/                  q search, selected q, final per-image decisions
  saec/                  same-adapter comparison and per-image decisions
  metrics.csv            combined test metrics
  inputs.json            recorded comparison inputs
```

Rates are fractions, not percentages. Missing KSDD2 semantic metrics stay empty.
TypeF1 is a harmonic mean of the project's TypeHit-A/P; it is not claimed to be a
standard multiclass classification F1. ExplainHit is a keyword heuristic, not an
independent human judgment. Cached generation timings are not end-to-end latency.

## Controlled fixed-local comparison

`--protocol fixed-local` reuses the committed detector-score and SAEC-mask tables
while retraining the multimodal adapters. This is explicitly a different protocol
from retraining the local detector. It requires only public base models and the
selected dataset images, not teacher/YOLO/Imagenette downloads.

```bash
python pipeline.py --run fixedlocal1 --protocol fixed-local
```

Do not describe this as fresh local-detector training. SAEC here is the preserved
complexity/confidence route with the **same three-field adapter** as UACR, not
binary-adapter SAEC. Its complexity quantile uses the evaluated image set without
labels. [Step-by-step commands and parameters](docs/REPRODUCING.md) explain both
protocols, resume behavior, metrics and known limitations.

## Tests and attribution

```bash
python -m unittest discover -s tests -v
python environment.py
```

Tests use synthetic image files for wiring checks; they do not prove model quality.
Public download sources and dataset licenses are linked in the resource guides.
Read [THIRD_PARTY.md](THIRD_PARTY.md) before redistributing data or upstream code.
